# Quick Revision

Remember:

```python
ord('A')      # Character → Unicode value
chr(65)       # Unicode value → Character
```

Comparison operators:

```python
==   # Equal to
!=   # Not equal to
>    # Greater than
<    # Less than
>=   # Greater than or equal to
<=   # Less than or equal to
```

Important examples:

```python
ord('A')      # 65
ord('Z')      # 90
ord('a')      # 97
ord('z')      # 122
ord('0')      # 48
ord('9')      # 57
```

**Important:** Python compares characters and strings according to their Unicode code-point values.
