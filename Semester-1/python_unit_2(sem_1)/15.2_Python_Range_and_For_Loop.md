# Quick Revision

## Three Forms of `range()`

### 1. `range(stop)`

```python
range(5)
```

Equivalent to:

```python
range(0, 5, 1)
```

---

### 2. `range(start, stop)`

```python
range(2, 6)
```

Equivalent to:

```python
range(2, 6, 1)
```

---

### 3. `range(start, stop, step)`

```python
range(2, 10, 2)
```

Here:

```text
start = 2
stop  = 10
step  = 2
```

Generated values:

```text
2 4 6 8
```

---

# Important Rules

1. `range()` starts from `0` when `start` is not provided.
2. The default `step` is `1`.
3. The `stop` value is always excluded.
4. A positive step moves forward.
5. A negative step moves backward.
6. `step = 0` is not allowed.
7. A wrong direction can produce an empty range.
8. One execution of the loop body is called an **iteration**.

---

# Memory Trick

```text
START → Where do I begin?

STOP  → Where do I stop?
        (STOP is excluded)

STEP  → How much do I move?
```

Example:

```python
range(2, 10, 2)
```

Think:

```text
START = 2
STOP  = 10
STEP  = 2

2 → 4 → 6 → 8 → stop
```
