**Event Listeners in JavaScript**

### What is an Event Listener?
An **event listener** is a way to tell JavaScript:  
“When this thing happens (click, key press, form submit, etc.), run this code.”

The modern and recommended way is:

```js
element.addEventListener(eventType, functionToRun);
```

You can also remove it later with `removeEventListener`.

---

### 1. Mouse Events
These fire when the user interacts with the mouse (or trackpad).

| Event          | When it fires                          |
|----------------|----------------------------------------|
| `click`        | User clicks an element                 |
| `dblclick`     | User double-clicks                     |
| `mouseover`    | Mouse enters the element               |
| `mouseout`     | Mouse leaves the element               |
| `mousedown`    | Mouse button is pressed down           |
| `mouseup`      | Mouse button is released               |
| `mousemove`    | Mouse is moving over the element       |
| `contextmenu`  | Right-click (context menu)             |

#### Examples + Real Use Cases

**Example 1 – Click**
```js
const btn = document.querySelector("#submitBtn");

btn.addEventListener("click", function () {
  alert("Button was clicked!");
});
```
**Real use case:** Submit a form, open a modal, like a post, add to cart.

**Example 2 – Mouseover / Mouseout (Hover effect)**
```js
const card = document.querySelector(".product-card");

card.addEventListener("mouseover", () => {
  card.style.boxShadow = "0 8px 20px rgba(0,0,0,0.2)";
});

card.addEventListener("mouseout", () => {
  card.style.boxShadow = "none";
});
```
**Real use case:** Highlight cards, show extra info on hover, change button color.

**Example 3 – Context Menu (Right Click)**
```js
document.addEventListener("contextmenu", function (e) {
  e.preventDefault(); // stop the default right-click menu
  alert("Custom menu can be shown here");
});
```
**Real use case:** Custom right-click menus in web apps (like Google Docs or design tools).

### 2. Keyboard Events
These fire when the user presses keys.

| Event       | When it fires                     |
|-------------|-----------------------------------|
| `keydown`   | Key is pressed down               |
| `keyup`     | Key is released                   |
| `keypress`  | (Older, mostly avoided now)       |

#### Examples + Real Use Cases

**Example 1 – Detect specific key (Enter)**
```js
const input = document.querySelector("#search");

input.addEventListener("keydown", function (e) {
  if (e.key === "Enter") {
    console.log("Searching for:", input.value);
  }
});
```
**Real use case:** Search bar – press Enter to search without clicking a button.

**Example 2 – Detect Escape key**
```js
document.addEventListener("keydown", function (e) {
  if (e.key === "Escape") {
    closeModal(); // your function to close a popup
  }
});
```
**Real use case:** Close modals, dropdowns, or lightboxes with the Escape key.

**Example 3 – Prevent typing numbers only**
```js
const phoneInput = document.querySelector("#phone");

phoneInput.addEventListener("keydown", function (e) {
  // Allow backspace, delete, arrows, etc.
  if (["Backspace", "Delete", "ArrowLeft", "ArrowRight", "Tab"].includes(e.key)) {
    return;
  }
  // Block if not a number
  if (!/^\d$/.test(e.key)) {
    e.preventDefault();
  }
});
```
**Real use case:** Restrict input fields (phone number, PIN, quantity).

### 3. Form Events
These are related to form elements (`input`, `select`, `textarea`, `form`).

| Event       | When it fires                              |
|-------------|--------------------------------------------|
| `submit`    | Form is submitted                          |
| `input`     | Value of input changes (real-time)         |
| `change`    | Value changes and element loses focus      |
| `focus`     | Element gets focus                         |
| `blur`      | Element loses focus                        |
| `reset`     | Form is reset                              |

#### Examples + Real Use Cases

**Example 1 – Form Submit**
```js
const form = document.querySelector("#loginForm");

form.addEventListener("submit", function (e) {
  e.preventDefault(); // stop page reload
  console.log("Form submitted!");
  // send data with fetch()
});
```
**Real use case:** Login, signup, contact forms (always use `preventDefault` if you handle it with JS).

**Example 2 – Live Search / Live Validation (`input`)**
```js
const searchBox = document.querySelector("#liveSearch");

searchBox.addEventListener("input", function () {
  console.log("Current value:", searchBox.value);
  // filter a list in real time
});
```
**Real use case:** Live search bars, character counters, real-time form validation.

**Example 3 – Focus & Blur (Highlight field)**
```js
const email = document.querySelector("#email");

email.addEventListener("focus", () => {
  email.style.border = "2px solid blue";
});

email.addEventListener("blur", () => {
  email.style.border = "1px solid #ccc";
});
```
**Real use case:** Better UX – highlight the active input field.

### 4. Window / Document Events
These listen on the whole page or browser window.

| Event              | When it fires                              |
|--------------------|--------------------------------------------|
| `load`             | Page and all resources finished loading    |
| `DOMContentLoaded` | HTML is fully loaded (faster than load)    |
| `resize`           | Browser window is resized                  |
| `scroll`           | User scrolls the page                      |
| `beforeunload`     | User is about to leave the page            |

#### Examples + Real Use Cases

**Example 1 – DOMContentLoaded**
```js
document.addEventListener("DOMContentLoaded", function () {
  console.log("HTML is ready!");
  // safe place to select elements and add listeners
});
```
**Real use case:** Run code as soon as the HTML is ready (preferred over putting script at the bottom).

**Example 2 – Scroll**
```js
window.addEventListener("scroll", function () {
  if (window.scrollY > 300) {
    document.querySelector(".back-to-top").style.display = "block";
  } else {
    document.querySelector(".back-to-top").style.display = "none";
  }
});
```
**Real use case:** Show “Back to Top” button, sticky navbar, infinite scroll, progress bar.

**Example 3 – Resize**
```js
window.addEventListener("resize", function () {
  console.log("Window width:", window.innerWidth);
  // change layout or hide/show elements
});
```
**Real use case:** Responsive design adjustments, recalculate canvas size, mobile menu behavior.

### 5. Touch Events (Mobile)
Important for mobile devices.

| Event         | When it fires                     |
|---------------|-----------------------------------|
| `touchstart`  | Finger touches the screen         |
| `touchend`    | Finger is lifted                  |
| `touchmove`   | Finger moves while touching       |
| `touchcancel` | Touch is interrupted              |

#### Examples + Real Use Cases

**Example 1 – Touchstart**
```js
const button = document.querySelector("#mobileBtn");

button.addEventListener("touchstart", function () {
  button.style.background = "green";
});
```
**Real use case:** Instant feedback on mobile buttons (feels faster than waiting for click).

**Example 2 – Swipe detection (basic)**
```js
let startX = 0;

document.addEventListener("touchstart", (e) => {
  startX = e.touches[0].clientX;
});

document.addEventListener("touchend", (e) => {
  const endX = e.changedTouches[0].clientX;
  if (startX - endX > 50) {
    console.log("Swiped Left");
  } else if (endX - startX > 50) {
    console.log("Swiped Right");
  }
});
```
**Real use case:** Image carousels, mobile navigation drawers, story viewers (Instagram-style).

**Example 3 – Prevent zoom on double-tap (sometimes needed)**
```js
document.addEventListener("touchstart", function (e) {
  if (e.touches.length > 1) {
    e.preventDefault(); // prevent pinch zoom if needed
  }
}, { passive: false });
```
**Real use case:** Games or drawing apps where you want full control over touch.

### Bonus: Other Useful Events

| Event            | Common Use Case                          |
|------------------|------------------------------------------|
| `change`         | Dropdown selection, checkbox, radio      |
| `dragstart` / `drop` | Drag and drop file upload or sorting  |
| `copy` / `paste` | Detect copy-paste actions                |
| `offline` / `online` | Show “You are offline” message        |
| `visibilitychange` | Pause video when user switches tab     |

---

### Best Practices for Beginners

1. Prefer `addEventListener` over `onclick = ...`
2. Always use `e.preventDefault()` when you don’t want the default browser action.
3. Use `DOMContentLoaded` if your script is in the `<head>`.
4. For performance on scroll/resize/mousemove → use throttling or debouncing later.
5. You can add multiple listeners to the same element.
