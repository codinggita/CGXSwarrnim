### 1. Introduction

HTML creates the structure of a webpage (headings, buttons, paragraphs, etc.).  
JavaScript adds **behavior** and **interactivity** (changing text, handling clicks, showing messages, etc.).

To make JavaScript work with HTML, we need to **connect** them. There are three main ways to do this.

---

### 2. Three Ways to Connect JavaScript with HTML

#### Method 1: Inline JavaScript

JavaScript is written **directly inside HTML tags** using event attributes like `onclick`.

**Example:**

```html
<button onclick="alert('Button clicked!')">Click Me</button>

<button onclick="document.getElementById('demo').innerHTML = 'Text Changed!'">
  Change Text
</button>
<p id="demo">Original Text</p>
```

**Pros:**
- Very quick for testing

**Cons:**
- Hard to manage
- Mixes HTML and JavaScript
- Not recommended for real projects

---

#### Method 2: Internal JavaScript

JavaScript is written inside a `<script>` tag in the same HTML file.

**Example:**

```html
<!DOCTYPE html>
<html>
<head>
  <title>Internal JS</title>
</head>
<body>
  <h1 id="heading">Hello</h1>
  <button id="btn">Click Me</button>

  <script>
    document.getElementById("btn").addEventListener("click", function() {
      document.getElementById("heading").innerHTML = "Hello JavaScript!";
      document.getElementById("heading").style.color = "blue";
    });
  </script>
</body>
</html>
```

**Best place for the script:** Just before the closing `</body>` tag.

---

#### Method 3: External JavaScript (Best Method)

JavaScript is written in a **separate `.js` file** and linked to the HTML.

**Step 1: HTML file (`index.html`)**

```html
<!DOCTYPE html>
<html>
<head>
  <title>External JS</title>
</head>
<body>
  <h1 id="title">Welcome</h1>
  <button id="changeBtn">Change Title</button>
  <p id="info"></p>

  <script src="script.js"></script>
</body>
</html>
```

**Step 2: JavaScript file (`script.js`)**

```js
const title = document.getElementById("title");
const button = document.getElementById("changeBtn");
const info = document.getElementById("info");

button.addEventListener("click", function() {
  title.innerHTML = "Title Changed by External JS!";
  title.style.color = "green";
  info.innerHTML = "This message comes from an external file.";
});
```

**Why this is best:**
- Code is clean and organized
- Easy to reuse
- Easy to maintain
- Browser can cache the `.js` file

---

### 3. Understanding How Scripts Load (Very Important)

When the browser reads an HTML page, it goes from **top to bottom**.

How a script behaves depends on whether it has **no attribute**, **`defer`**, or **`async`**.

---

#### A. Normal Script (No Attribute)

```html
<script src="script.js"></script>
```

**What happens:**
1. Browser reaches the script tag
2. **Stops** reading HTML
3. Downloads the JavaScript
4. Runs the JavaScript
5. Continues reading the remaining HTML

**Problem:** It blocks the page while downloading and running.

---

#### B. `defer` Attribute (Most Recommended)

```html
<script src="script.js" defer></script>
```

**Simple meaning:**  
“Download the script in the background, but **wait** until the entire HTML is fully loaded before running it.”

**What happens:**
1. Browser continues reading HTML
2. Downloads the script in the background
3. Waits until the full HTML is ready
4. Then runs the script
5. Multiple `defer` scripts run **in order**

**Best for:** Almost all your own JavaScript (especially when working with HTML elements).

---

#### C. `async` Attribute

```html
<script src="script.js" async></script>
```

**Simple meaning:**  
“Download the script in the background and run it **as soon as it is ready** (don’t wait for HTML to finish).”

**What happens:**
1. Browser continues reading HTML
2. Downloads the script in the background
3. As soon as the script is downloaded → runs it immediately
4. Does **not** guarantee order if multiple scripts are used

**Best for:** Independent scripts only (like analytics or ads).  
**Not good** when your script needs HTML elements.

---

### 4. Clear Difference Between Normal, `async`, and `defer`

| Feature                        | Normal Script     | `async`              | `defer`                  |
|--------------------------------|-------------------|----------------------|--------------------------|
| Stops HTML while downloading?  | Yes               | No                   | No                       |
| Stops HTML while running?      | Yes               | Yes                  | No (runs after HTML)     |
| Waits for full HTML?           | No                | No                   | Yes                      |
| Runs in order (multiple files)?| Yes               | No                   | Yes                      |
| Safe for working with HTML?    | Risky             | Risky                | **Safe**                 |
| Recommended for beginners?     | No                | Rarely               | **Yes**                  |

---

### 5. Simple Rule to Remember

- Use **`defer`** → when your JavaScript works with the page (buttons, text, forms, etc.)
- Use **`async`** → only for independent scripts
- Avoid normal scripts in the middle of the page

---

### 6. Best Practices

| Practice                              | Recommendation                          |
|---------------------------------------|-----------------------------------------|
| Preferred method                      | External JavaScript                     |
| Best attribute                        | `defer`                                 |
| Placement of script                   | Before `</body>` or in `<head>` with `defer` |
| Event handling                        | Use `addEventListener`                  |
| Selecting elements                    | Prefer `querySelector` / `getElementById` |
| Avoid                                 | Inline JavaScript in real projects      |

### 7. Complete Practical Example

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Complete Example</title>
  <script src="app.js" defer></script>
</head>
<body>
  <h1 id="heading">Learning JavaScript</h1>
  
  <button id="btn1">Change Heading</button>
  <button id="btn2">Change Color</button>
  <button id="btn3">Show Message</button>

  <p id="output"></p>
</body>
</html>
```

**app.js**

```js
const heading = document.getElementById("heading");
const btn1 = document.getElementById("btn1");
const btn2 = document.getElementById("btn2");
const btn3 = document.getElementById("btn3");
const output = document.getElementById("output");

btn1.addEventListener("click", function() {
  heading.innerHTML = "JavaScript is Successfully Connected!";
});

btn2.addEventListener("click", function() {
  heading.style.color = "crimson";
  heading.style.backgroundColor = "#ffe6e6";
});

btn3.addEventListener("click", function() {
  output.innerHTML = "You have learned how to connect JavaScript with HTML!";
});
```


**Introduction to DOM Manipulation**

---

### 1. What is the DOM?

**DOM** stands for **Document Object Model**.

Simple meaning:  
When a browser loads an HTML page, it converts the HTML into a **tree-like structure** of objects. This structure is called the **DOM**.

You can think of it like this:

- HTML is the written document
- DOM is the live version of that document that JavaScript can read and change

JavaScript cannot directly change the HTML file.  
It can only change the **DOM** (the live version in the browser).

---

### 2. Why Do We Need DOM Manipulation?

DOM manipulation means **using JavaScript to change the webpage after it has loaded**.

With DOM manipulation you can:
- Change text
- Change colors and styles
- Show or hide elements
- Add or remove content
- Respond to user actions (clicks, typing, etc.)

Without DOM manipulation, websites would be static (no interactivity).

---

### 3. How to Select HTML Elements

Before you can change anything, you must first **select** the element.

Here are the most common ways:

#### A. `getElementById()` (Most Common for Beginners)

```js
const heading = document.getElementById("title");
```

#### B. `querySelector()` (Modern & Flexible)

```js
const heading = document.querySelector("#title");     // by ID
const button = document.querySelector(".btn");        // by class
const firstPara = document.querySelector("p");        // by tag
```

#### C. `querySelectorAll()` (Selects Multiple Elements)

```js
const allButtons = document.querySelectorAll(".btn");
```

**Tip:**  
- Use `#` for ID  
- Use `.` for class  
- Just write the tag name for tags

---

### 4. Changing Content

Once you select an element, you can change its content.

#### Using `innerHTML`

```js
const heading = document.getElementById("title");
heading.innerHTML = "New Heading Text";
```

#### Using `textContent` (Safer)

```js
heading.textContent = "New Heading Text";
```

**Difference:**
- `innerHTML` → Can include HTML tags
- `textContent` → Only plain text (safer)

---

### 5. Changing Styles

You can change CSS styles using JavaScript.

```js
const heading = document.getElementById("title");

heading.style.color = "red";
heading.style.backgroundColor = "yellow";
heading.style.fontSize = "30px";
heading.style.padding = "10px";
```

**Note:**  
In CSS we write `background-color`, but in JavaScript we write `backgroundColor` (camelCase).

---

### 6. Changing Attributes

You can also change attributes like `src`, `href`, `class`, etc.

```js
const image = document.getElementById("myImage");
image.src = "new-photo.jpg";

const link = document.getElementById("myLink");
link.href = "https://www.example.com";
```

---

### 7. Adding Event Listeners (Making Things Interactive)

To respond when a user clicks a button:

```js
const button = document.getElementById("btn");

button.addEventListener("click", function() {
  // code that runs when button is clicked
  document.getElementById("title").textContent = "Button was clicked!";
});
```

Common events:
- `click`
- `mouseover`
- `mouseout`
- `keydown`
- `submit`

---

### 8. Complete Beginner Example

**HTML:**

```html
<!DOCTYPE html>
<html>
<head>
  <title>DOM Manipulation</title>
</head>
<body>
  <h1 id="heading">Hello World</h1>
  <p id="message">This is a paragraph.</p>
  <button id="btn">Click Me</button>

  <script src="script.js" defer></script>
</body>
</html>
```

**JavaScript (`script.js`):**

```js
const heading = document.getElementById("heading");
const message = document.getElementById("message");
const button = document.getElementById("btn");

button.addEventListener("click", function() {
  // Change text
  heading.textContent = "DOM is Working!";
  
  // Change style
  heading.style.color = "crimson";
  heading.style.backgroundColor = "#ffe6e6";
  
  // Change paragraph
  message.textContent = "You successfully manipulated the DOM!";
  message.style.fontSize = "18px";
});
```
