**JavaScript Notes: Creating Elements, Adding Content, Adding/Removing Classes**  

---

### 1. Creating a New HTML Element

To create a new element in JavaScript, we use:

```js
document.createElement("tagName")
```

**Example:**
```js
const heading = document.createElement("h1");
const paragraph = document.createElement("p");
const button = document.createElement("button");
const div = document.createElement("div");
const image = document.createElement("img");
```

At this point the element only exists in JavaScript memory. It is **not yet visible** on the page.

---

### 2. Adding Content to an Element

There are 3 common ways:

| Method          | What it does                              | Can add HTML tags? | Recommended? |
|-----------------|-------------------------------------------|--------------------|--------------|
| `textContent`   | Adds plain text                           | No                 | Best choice for text |
| `innerText`     | Adds visible text (respects CSS)          | No                 | Less preferred |
| `innerHTML`     | Adds HTML code                            | Yes                | Use carefully |

#### Examples:

**Using `textContent` (Safest for text)**
```js
const heading = document.createElement("h1");
heading.textContent = "Hello World!";
```

**Using `innerHTML` (When you need HTML)**
```js
const div = document.createElement("div");
div.innerHTML = "<h2>Welcome</h2><p>This is a <strong>paragraph</strong></p>";
```

**Using `innerText`**
```js
const p = document.createElement("p");
p.innerText = "This is some text";
```

### 3. Adding the Element to the Page

Creating is not enough — you must **insert** it into the page.

Common methods:

| Method              | Description                              |
|---------------------|------------------------------------------|
| `appendChild()`     | Adds at the end (old but still common)   |
| `append()`          | Modern way (can add multiple things)     |
| `prepend()`         | Adds at the beginning                    |
| `insertBefore()`    | Inserts before a specific element        |
| `replaceWith()`     | Replaces an existing element             |

#### Examples:

```js
const container = document.querySelector(".container");
const newHeading = document.createElement("h2");
newHeading.textContent = "I am new!";

// Method 1
container.appendChild(newHeading);

// Method 2 (Modern)
container.append(newHeading);

// Add at the beginning
container.prepend(newHeading);
```

**Practical Example – Create a complete card**
```js
const card = document.createElement("div");
card.classList.add("card");

const title = document.createElement("h3");
title.textContent = "Product Name";

const price = document.createElement("p");
price.textContent = "₹999";

const btn = document.createElement("button");
btn.textContent = "Add to Cart";

card.append(title, price, btn);           // add multiple at once
document.body.append(card);
```

### 4. Working with Classes (Very Important)

Modern and best way → use **`classList`**

#### Main Methods:

| Method                        | What it does                              |
|-------------------------------|-------------------------------------------|
| `classList.add("class")`      | Adds one or more classes                  |
| `classList.remove("class")`   | Removes one or more classes               |
| `classList.toggle("class")`   | Adds if not present, removes if present   |
| `classList.contains("class")` | Returns `true` or `false`                 |
| `classList.replace("old", "new")` | Replaces a class                       |

#### Examples:

```js
const box = document.querySelector(".box");

// Add class
box.classList.add("active");
box.classList.add("highlight", "shadow");   // multiple classes

// Remove class
box.classList.remove("active");
box.classList.remove("highlight", "shadow");

// Toggle class (very useful)
box.classList.toggle("dark-mode");

// Check if class exists
if (box.classList.contains("active")) {
  console.log("Box is active");
}

// Replace class
box.classList.replace("old-style", "new-style");
```

#### Real Life Examples:

**1. Toggle Dark Mode**
```js
const themeBtn = document.querySelector("#themeBtn");

themeBtn.addEventListener("click", () => {
  document.body.classList.toggle("dark-mode");
});
```

**2. Active Menu Item**
```js
const links = document.querySelectorAll(".nav-link");

links.forEach(link => {
  link.addEventListener("click", () => {
    // Remove active from all
    links.forEach(l => l.classList.remove("active"));
    // Add active to clicked one
    link.classList.add("active");
  });
});
```

**3. Show/Hide Password**
```js
const passwordInput = document.querySelector("#password");
const toggleBtn = document.querySelector("#togglePassword");

toggleBtn.addEventListener("click", () => {
  passwordInput.classList.toggle("show-password");
  
  if (passwordInput.classList.contains("show-password")) {
    passwordInput.type = "text";
    toggleBtn.textContent = "Hide";
  } else {
    passwordInput.type = "password";
    toggleBtn.textContent = "Show";
  }
});
```

### 5. Extra Important Things

#### A. Setting Attributes

```js
const img = document.createElement("img");

img.setAttribute("src", "photo.jpg");
img.setAttribute("alt", "Product Image");
img.setAttribute("width", "300");

// Shorter way for common attributes
img.src = "photo.jpg";
img.alt = "Product Image";
img.id = "mainImage";
img.title = "Click to zoom";
```

#### B. Getting & Removing Attributes

```js
const link = document.querySelector("a");

console.log(link.getAttribute("href"));   // get value
link.removeAttribute("target");           // remove attribute
```

#### C. Adding Inline Styles

```js
const box = document.createElement("div");

box.style.backgroundColor = "red";
box.style.color = "white";
box.style.padding = "20px";
box.style.borderRadius = "10px";
box.style.fontSize = "18px";
```

**Better practice:** Prefer classes over many inline styles.

#### D. Removing an Element

```js
const element = document.querySelector(".old-item");
element.remove();                    // modern way

// Old way
// element.parentElement.removeChild(element);
```

#### E. Creating Element + Content + Class in one go (Clean way)

```js
function createCard(title, price) {
  const card = document.createElement("div");
  card.classList.add("product-card");

  card.innerHTML = `
    <h3>${title}</h3>
    <p>Price: ₹${price}</p>
    <button class="btn">Buy Now</button>
  `;

  return card;
}

// Usage
const newCard = createCard("Wireless Mouse", 799);
document.querySelector(".products").append(newCard);
```

### 6. Complete Practical Example

**Create a Todo Item dynamically**

```js
const todoList = document.querySelector("#todoList");
const addBtn = document.querySelector("#addBtn");
const input = document.querySelector("#todoInput");

addBtn.addEventListener("click", () => {
  const text = input.value.trim();
  if (text === "") return;

  // Create elements
  const li = document.createElement("li");
  li.classList.add("todo-item");

  const span = document.createElement("span");
  span.textContent = text;

  const deleteBtn = document.createElement("button");
  deleteBtn.textContent = "Delete";
  deleteBtn.classList.add ind("delete-btn");

  // Add event to delete button
  deleteBtn.addEventListener("click", () => {
    li.remove();
  });

  // Assemble
  li.append(span, deleteBtn);
  todoList.append(li);

  input.value = ""; // clear input
});
```

### Quick Summary

| Task                        | Method                              |
|-----------------------------|-------------------------------------|
| Create element              | `document.createElement("div")`     |
| Add text                    | `element.textContent = "..."`       |
| Add HTML                    | `element.innerHTML = "..."`         |
| Add class                   | `element.classList.add("name")`     |
| Remove class                | `element.classList.remove("name")`  |
| Toggle class                | `element.classList.toggle("name")`  |
| Add to page                 | `parent.append(element)`            |
| Remove from page            | `element.remove()`                  |
| Set attribute               | `element.setAttribute()` or `element.src = ""` |
