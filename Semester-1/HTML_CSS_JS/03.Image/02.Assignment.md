
**1.** Create an image tag that displays an image named `flower.jpg` which is in the **same folder** as your HTML file. Add proper `alt` text.
Answer:flower.jpg in the same folder
<img src="flower.jpg" alt="Beautiful flower">

**2.** Display an image named `logo.png` that is stored inside a folder called `images`. Your HTML file is outside the `images` folder.  
Also give the image a width of `200px`.
Answer:logo.png inside the images folder
<img src="images/logo.png" alt="Website logo" width="200px">

**3.** An image named `banner.jpg` is inside a folder called `assets/images`. Your HTML file is in the root folder. Write the correct `src` path and add `alt` text.
Answer:banner.jpg inside assets/images
<img src="assets/images/banner.jpg" alt="Website banner">

**4.** Your HTML file is inside a folder called `pages`. The image `photo.jpg` is in the root folder. Write the correct path to display the image.
Answer:Image in the root folder, HTML inside pages
Since the HTML file is inside pages, we need to go one folder up using ../.
<img src="../photo.jpg" alt="Photo">
Explanation:
.. → goes up from the pages folder to the root folder.
photo.jpg → the image located in the root folder.

**5.** Display an image with:
- `src` = `images/nature.jpg`
- `alt` = "Beautiful nature view"
- `width` = 300
- `height` = 200
Answer:Image with src, alt, width, and height
<img src="images/nature.jpg" alt="Beautiful nature view" width="300" height="200">

**6.** Add a `title` attribute to an image so that when the user hovers over it, the text “Click to view full size” appears.
Answer:Add a title attribute
<img src="images/photo.jpg" alt="Photo" title="Click to view full size">

**7.** Create an image that should load **only when the user scrolls near it** (lazy loading). Use an image from the `images` folder.
Answer:Use loading="lazy" so the image loads when the user scrolls near it.
<img src="images/nature.jpg" alt="Beautiful nature view" loading="lazy">

**8.** Create a hero image that should load **immediately** when the page opens (eager loading).
Answer:Use loading="eager" so the image is requested immediately when the page loads.
<img src="images/hero.jpg" alt="Hero image" loading="eager">

**9.** Write an image tag using `loading="auto"` and explain in one line what the browser will decide.
Answer:<img src="images/photo.jpg" alt="Photo" loading="auto">
The browser decides whether to load the image immediately or lazily based on its own judgment.

**10.** Create a responsive image using `srcset` with three versions:
- `small.jpg` (400w)
- `medium.jpg` (800w)
- `large.jpg` (1200w)

Also add a normal `src` as fallback.
Answer:Responsive image using srcset
<img
    src="large.jpg"
    srcset="small.jpg 400w, medium.jpg 800w, large.jpg 1200w"
    alt="Responsive image">
Here, the browser chooses the most appropriate image size based on the screen and display conditions.

**11.** Create a complete image tag that includes all these attributes:
- Image is inside `images/` folder
- `alt` text
- `width` and `height`
- `loading="lazy"`
- `title`
- `srcset` with two sizes
- Answer:Complete image tag
<img
    src="images/photo.jpg"
    alt="Beautiful photo"
    width="800"
    height="600"
    loading="lazy"
    title="View the photo"
    srcset="images/photo-small.jpg 400w, images/photo-large.jpg 800w">

**12.** Create two images side by side:
- First image loads immediately (`eager`) and is a logo from `assets/logo.png`
- Second image loads lazily and is a product photo from `images/products/shoe.jpg`
Both should have proper `alt` text and width of 250px.
Answer:Two images side by side
<img src="assets/logo.png"
     alt="Company logo"
     width="250"
     loading="eager">

<img src="images/products/shoe.jpg"
     alt="Product shoe"
     width="250"
     loading="lazy">
Since <img> elements are inline by default, they will appear side by side if there is enough horizontal space.
