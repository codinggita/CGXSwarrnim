### Question 34  
Create a comparison-style description list.  
a) Create a description list.  
b) Add three terms related to list types in HTML.  
c) Give each term a clear and meaningful description.
Answer:<dl>
    <dt>Unordered List</dt>
    <dd>Displays a collection of items using bullet points. It is created with the &lt;ul&gt; element.</dd>

    <dt>Ordered List</dt>
    <dd>Displays items in a specific sequence using numbers or letters. It is created with the &lt;ol&gt; element.</dd>

    <dt>Description List</dt>
    <dd>Displays terms along with their descriptions. It uses the &lt;dl&gt;, &lt;dt&gt;, and &lt;dd&gt; elements.</dd>
</dl>
